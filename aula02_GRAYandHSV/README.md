## RGB -> Gray
- média simples
    - Y = (R + G + B)/3
- média ponderada (mais adequada)
    - Y = 0.299.R + 0.587.G + 0.114.B

## RGB x CMY/CMYK x HSV/HSL
- RGB é aditivo (soma gera branco)
- CMY é subtrativo (soma gera preto)
- HSV
    - Hue
        - palheta de cor (0-180)
    - Saturation
        - vivacidade(0 morto e 1 vivo)
    - Value
        - brilho (0 escuro e 1 claro)
